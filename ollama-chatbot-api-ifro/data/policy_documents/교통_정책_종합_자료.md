# 교통 정책 종합 자료

## 1. 국가 교통 정책 기본 방향

### 1.1 제4차 국가교통물류발전기본계획 (2021-2030)
**비전**: 사람 중심의 지속가능한 교통물류 체계 구축

**주요 목표:**
- **교통 안전**: 교통사고 사망자 50% 감소 (2030년)
- **친환경 교통**: 온실가스 배출량 30% 감소 (2030년)
- **대중교통**: 대중교통 이용률 50% 달성 (2030년)
- **교통 접근성**: 교통 소외지역 0% 달성 (2030년)

**핵심 전략:**
1. **스마트 교통**: AI, 빅데이터 활용한 교통 시스템 구축
2. **친환경 교통**: 전기차, 수소차 등 친환경 교통수단 확대
3. **대중교통 중심**: 대중교통 우선 정책 추진
4. **교통 안전**: 교통사고 제로화 정책 추진

### 1.2 교통 혁신 정책
**자율주행차 정책**
- 2030년까지 자율주행차 상용화
- 자율주행차 관련 법령 정비
- 자율주행차 테스트베드 구축

**전기차 정책**
- 2030년까지 전기차 300만대 보급
- 전기차 충전 인프라 확충
- 전기차 관련 세제 혜택 확대

**스마트 교통 정책**
- 교통 정보 실시간 제공
- 교통 신호 최적화
- 교통 체증 예측 및 대응

## 2. 지방자치단체 교통 정책

### 2.1 서울시 교통 정책
**서울시 교통정책 기본계획 (2021-2030)**
- **비전**: 사람 중심의 스마트 교통도시
- **목표**: 교통사고 사망자 50% 감소, 대중교통 이용률 70% 달성

**주요 정책:**
- **버스 전용차로 확대**: 주요 간선도로 버스 전용차로 확대
- **지하철 확장**: 신규 지하철 노선 건설
- **자전거 도로**: 자전거 도로 1,000km 확충
- **보행자 중심**: 보행자 중심 도시 조성

**성과:**
- 버스 운행 속도 20% 향상
- 대중교통 이용률 15% 증가
- 교통 체증 10% 감소
- 대기오염 5% 감소

### 2.2 부산시 교통 정책

- **버스 정책**: 버스 노선 최적화
- **자전거 정책**: 자전거 도로 확충
- **해양 교통**: 해양 교통 인프라 구축

**성과:**
- 지하철 이용률 25% 증가
- 교통 체증 15% 감소
- 자전거 이용률 30% 증가
- 해양 교통 이용률 20% 증가

### 2.3 대전시 교통 정책
